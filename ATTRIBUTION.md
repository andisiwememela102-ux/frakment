# Attribution

If you use Frakment in your project, we appreciate a credit line in your README or footer:

> Based on [Frakment](https://github.com/arrafipd/frakment).

This is a courtesy, not a legal requirement. The MIT license only requires
that you keep the copyright notice and license text when you redistribute
the source code. See [LICENSE](./LICENSE).

## What counts as clear attribution

- **Good**: a README line, a footer link, or an "About" section that names
  Frakment and links to the repo.
- **Nice to have, but not required**: a source code comment.

If you are unsure, open an issue and ask.
